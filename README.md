# Data-Analysis-Using-Excel

# 📊 Overview

This project completes **Task 2 of the Data Analyst Internship** assignment using Excel pivot tables and analytical insights.

## 📁 Dataset
- Superstore Sales Dataset

## 🛠 Tools Used
- Microsoft Excel
- GitHub

## 🔍 Work Done
- Cleaned and standardized the dataset
- Converted data into table format for dynamic analysis
- Created pivot tables for:
  - 📈 Total Sales by Category
  - 🌍 Sales by Region and Segment
  - 💰 Profit Margin analysis (Profit / Sales)
- Added slicers and a pivot chart for interactive analysis
- Derived meaningful business insights from the data

## 📂 Files Included
- `Superstore_Sales_Dataset.csv`
- `Pivot_Report.xlsx`
- `Pivot_Report.pdf`
- `Insights.txt`
- `README.md`

## ✅ Outcome
This task demonstrates practical skills in data cleaning, pivot table analysis, and insight-driven reporting for business decision-making.
